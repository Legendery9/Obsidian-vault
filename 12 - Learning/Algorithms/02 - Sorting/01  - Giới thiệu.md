# Định nghĩa
### Nhóm thuật toán sắp xếp

| Algorithm     | Ý nghĩa          |
| ------------- | ---------------- |
| **Insertion** | Insertion Sort   |
| **Selection** | Selection Sort   |
| **Bubble**    | Bubble Sort      |
| **Shell**     | Shell Sort       |
| **Merge**     | Merge Sort       |
| **Heap**      | Heap Sort        |
| **Quick**     | Quick Sort       |
| **Quick3**    | Quick Sort 3-way |

### Nhóm dữ liệu đầu vào

|Input|Ý nghĩa|
|---|---|
|**Random**|Mảng ngẫu nhiên|
|**Nearly Sorted**|Mảng gần như đã sắp xếp|
|**Reversed**|Mảng sắp xếp ngược|
|**Few Unique**|Mảng chỉ có ít giá trị khác nhau|
