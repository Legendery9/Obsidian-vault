| Algorithm                | Ý nghĩa                                         | Điều kiện                                   |
| ------------------------ | ----------------------------------------------- | ------------------------------------------- |
| **Linear Search**        | Duyệt từng phần tử từ đầu đến cuối              | Không cần sắp xếp                           |
| **Binary Search**        | Chia đôi phạm vi tìm kiếm                       | Mảng phải được sắp xếp                      |
| **Jump Search**          | Nhảy theo từng block                            | Mảng phải được sắp xếp                      |
| **Interpolation Search** | Ước lượng vị trí cần tìm                        | Mảng đã sort, dữ liệu phân bố tương đối đều |
| **Exponential Search**   | Tăng phạm vi theo cấp số nhân rồi Binary Search | Mảng đã sort                                |
| **Fibonacci Search**     | Dùng các số Fibonacci để chia phạm vi           | Mảng đã sort                                |
| **Ternary Search**       | Chia phạm vi thành 3 phần                       | Mảng đã sort                                |
| **Hash Search**          | Tìm thông qua Hash Table                        | Cần cấu trúc hash                           |
