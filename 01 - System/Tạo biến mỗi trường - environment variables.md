==**Được lưu sẵn để được đọc mà không cần hardcode trong code**.

# Spring boot dùng:
```properties
${VariablerName}
```
Thực chất Lệnh được dùng:
```java
System.getevn("VariablerName")
```
# Các bược tạo biến mỗi trường
1. Chọn: `Win + S`
2. Gõ: `environment variables`
3. Chọn: `Edit the system environment variables`
4. `Advanced -> 'Environment Variables...'`
5. Chọn `new...` và nhập `Variabler name` và `Variabler value` xong `OK`
# Nếu dự án vẫn không tìm thấy biến môi trường
