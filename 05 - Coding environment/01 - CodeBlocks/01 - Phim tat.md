# Phím tắt Code::Blocks

---

## Định nghĩa
Code::Blocks là một môi trường phát triển tích hợp (IDE) mã nguồn mở, miễn phí và hỗ trợ nhiều trình biên dịch khác nhau (mặc định là GCC/MinGW cho C/C++).

---

## Tác dụng
- **Tối ưu hóa thời gian soạn thảo:** Cho phép lập trình viên viết, biên dịch, chạy và debug mã nguồn C/C++ trực tiếp trong một giao diện duy nhất.
- **Tăng tốc thao tác:** Sử dụng các phím tắt bàn phím giúp giảm thiểu việc dùng chuột, tăng năng suất viết code.

---

## Bảng tham chiếu

### Phím tắt lập trình thường dùng trong Code::Blocks

| Nhóm chức năng | Tính năng | Phím tắt | Tác dụng thực tế |
| :--- | :--- | :--- | :--- |
| **Biên dịch & Chạy** | **Build & Run** | `F9` | Biên dịch toàn bộ thay đổi và chạy chương trình |
| | **Build** | `Ctrl + F9` | Chỉ biên dịch các file thay đổi (không chạy) |
| | **Run** | `Ctrl + F10` | Chạy chương trình đã biên dịch trước đó |
| **Debug mã nguồn** | **Debug** | `F8` | Bắt đầu chạy chương trình ở chế độ gỡ lỗi |
| | **Toggle Breakpoint**| `F5` | Đặt hoặc xóa điểm dừng (Breakpoint) |
| | **Step Into** | `F7` | Nhảy vào bên trong hàm đang gọi |
| | **Step Over** | `F8` (khi debug)| Chạy dòng tiếp theo, bỏ qua việc chui vào hàm |
| | **Step Out** | `Shift + F7` | Thoát nhanh ra khỏi hàm hiện tại |
| **Soạn thảo code** | **Comment / Uncomment** | `Ctrl + Shift + C` | Bật/tắt chú thích cho dòng hoặc khối code bôi đen |
| | **Code Completion** | `Ctrl + Space` | Gợi ý các từ khóa, biến hoặc phương thức |
| | **Auto-Indent** | `Ctrl + Shift + I` | Định dạng lại căn lề thụt đầu dòng tự động |
| | **Switch Header/Source** | `Ctrl + Tab` | Chuyển đổi qua lại cực nhanh giữa file `.h` và `.cpp` |
| **Tìm kiếm** | **Find** | `Ctrl + F` | Tìm kiếm từ khóa trong file hiện tại |
| | **Find in Files** | `Ctrl + Shift + F` | Tìm kiếm từ khóa trên toàn bộ project |
| | **Replace** | `Ctrl + R` | Tìm kiếm và thay thế từ khóa |

---

## Lưu ý
> [!warning] Lỗi phím tắt Debug
> Đôi khi các phím tắt debug như `F5` hay `F8` bị xung đột với phím tắt hệ thống hoặc các ứng dụng chạy ngầm khác. Bạn có thể thay đổi chúng bằng cách vào: **Settings** → **Editor** → **Keyboard Shortcuts**.
