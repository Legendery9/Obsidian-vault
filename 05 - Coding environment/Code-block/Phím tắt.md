| Tính năng                | Phím tắt / cách dùng   | Tác dụng                      |
| ------------------------ | ---------------------- | ----------------------------- |
| **Build & Run**          | `F9`                   | Biên dịch + chạy chương trình |
| **Build**                | `Ctrl + F9`            | Chỉ biên dịch                 |
| **Run**                  | `Ctrl + F10`           | Chạy chương trình             |
| **Debug**                | `F8`                   | Bắt đầu Debug                 |
| **Toggle Breakpoint**    | `F5`                   | Đặt/xóa breakpoint            |
| **Step Into**            | `F7`                   | Đi vào bên trong function     |
| **Step Over**            | `F8`*                  | Chạy qua dòng hiện tại        |
| **Step Out**             | `Shift + F7`*          | Thoát khỏi function hiện tại  |
| **Go to declaration**    | `Ctrl + Shift + .`*    | Đi tới khai báo               |
| **Find**                 | `Ctrl + F`             | Tìm trong file                |
| **Find in files**        | `Ctrl + Shift + F`     | Tìm toàn project              |
| **Replace**              | `Ctrl + R`             | Thay thế                      |
| **Comment**              | `Ctrl + Shift + C`     | Comment/uncomment             |
| **Code completion**      | `Ctrl + Space`         | Gợi ý code                    |
| **Function parameters**  | `Ctrl + Shift + Space` | Xem tham số function          |
| **Reindent**             | `Ctrl + Shift + I`     | Format/reindent code          |
| **Switch header/source** | `Ctrl + Tab`           | Chuyển `.h` ↔ `.cpp`          |
| **Build target**         | Toolbar                | Chọn Debug/Release            |
| **Project tree**         | Workspace              | Quản lý `.c/.cpp/.h`          |
