# 3.3 Cumulative Distribution Function

## Định nghĩa và tóm gọn

> [!abstract] Hàm phân phối tích lũy (Cumulative Distribution Function - CDF)
> **Hàm phân phối tích lũy** của biến ngẫu nhiên rời rạc $X$ là:
> $$F(x) = P(X \leq x) = \sum_{t \leq x} f(t)$$
> CDF cho biết xác suất để $X$ nhận giá trị **nhỏ hơn hoặc bằng** $x$. CDF là hàm bậc thang (step function) đối với biến rời rạc.

---

## Ký hiệu và tham số

> [!info] Các ký hiệu
> | Ký hiệu | Ý nghĩa |
> |---|---|
> | $F(x)$ | Hàm phân phối tích lũy tại $x$ |
> | $P(X \leq x)$ | Xác suất $X$ nhỏ hơn hoặc bằng $x$ |
> | $f(t)$ | PMF tại giá trị $t$ |
> | $\sum_{t \leq x} f(t)$ | Tổng PMF của tất cả giá trị $\leq x$ |

---

## Phân loại và Công thức

### Tính chất của CDF

**Tính chất 1:** Giới hạn
$$0 \leq F(x) \leq 1 \quad \text{với mọi } x$$

**Tính chất 2:** Đơn điệu không giảm
$$\text{Nếu } a < b \text{ thì } F(a) \leq F(b)$$

**Tính chất 3:** Giới hạn tại vô cực
$$\lim_{x \to -\infty} F(x) = 0, \quad \lim_{x \to +\infty} F(x) = 1$$

**Tính chất 4:** Liên tục phải (right-continuous)
$$F(x) = F(x^+) = \lim_{t \to x^+} F(t)$$

### Công thức tính xác suất từ CDF

$$P(a < X \leq b) = F(b) - F(a)$$

$$P(X > a) = 1 - F(a)$$

$$P(X = a) = F(a) - F(a^-)$$

trong đó $F(a^-)$ là giá trị CDF ngay trước $a$ (giới hạn trái).

> [!warning] Lưu ý quan trọng
> Chú ý dấu **nghiêm ngặt** và **không nghiêm ngặt**: $P(a < X \leq b) = F(b) - F(a)$, nhưng $P(a \leq X \leq b) = F(b) - F(a) + P(X = a) = F(b) - F(a^-)$. Nhầm dấu sẽ cho kết quả sai!

## Ví dụ Minh họa

### 📌 Ví dụ 1 — Constructing a CDF from a PMF

**Đề bài (Problem):** A random variable $X$ has PMF:

| $x$ | 1 | 2 | 3 | 4 |
|---|---|---|---|---|
| $f(x)$ | 0.1 | 0.3 | 0.4 | 0.2 |

Construct the CDF $F(x)$ and find $P(2 < X \leq 4)$.

> [!note] Lời giải
> **Bước 1:** Tính CDF tại mỗi điểm:
> $$F(1) = f(1) = 0.1$$
> $$F(2) = f(1) + f(2) = 0.1 + 0.3 = 0.4$$
> $$F(3) = f(1) + f(2) + f(3) = 0.4 + 0.4 = 0.8$$
> $$F(4) = f(1) + f(2) + f(3) + f(4) = 0.8 + 0.2 = 1.0$$
>
> **Bước 2:** CDF hoàn chỉnh:
> $$F(x) = \begin{cases} 0 & x < 1 \\ 0.1 & 1 \leq x < 2 \\ 0.4 & 2 \leq x < 3 \\ 0.8 & 3 \leq x < 4 \\ 1.0 & x \geq 4 \end{cases}$$
>
> **Bước 3:** Tính $P(2 < X \leq 4)$:
> $$P(2 < X \leq 4) = F(4) - F(2) = 1.0 - 0.4 = 0.6$$

### 📌 Ví dụ 2 — Using CDF to find probabilities

**Đề bài (Problem):** The CDF of a discrete random variable $X$ is given by:

$$F(x) = \begin{cases} 0 & x < 0 \\ 0.25 & 0 \leq x < 1 \\ 0.60 & 1 \leq x < 2 \\ 0.90 & 2 \leq x < 3 \\ 1.00 & x \geq 3 \end{cases}$$

Find (a) $P(X \leq 2)$, (b) $P(X > 1)$, and (c) $P(1 < X \leq 3)$.

> [!note] Lời giải
> **(a)** $P(X \leq 2)$:
> $$P(X \leq 2) = F(2) = 0.90$$
>
> **(b)** $P(X > 1)$:
> $$P(X > 1) = 1 - P(X \leq 1) = 1 - F(1) = 1 - 0.60 = 0.40$$
>
> **(c)** $P(1 < X \leq 3)$:
> $$P(1 < X \leq 3) = F(3) - F(1) = 1.00 - 0.60 = 0.40$$

### 📌 Ví dụ 3 — Recovering PMF from CDF

**Đề bài (Problem):** Given the CDF:

$$F(x) = \begin{cases} 0 & x < 1 \\ 0.15 & 1 \leq x < 3 \\ 0.55 & 3 \leq x < 5 \\ 0.85 & 5 \leq x < 7 \\ 1.00 & x \geq 7 \end{cases}$$

Find the PMF $f(x)$ and compute $P(3 \leq X < 7)$.

> [!note] Lời giải
> **Bước 1:** PMF = bước nhảy của CDF tại mỗi điểm:
> $$f(1) = F(1) - F(1^-) = 0.15 - 0 = 0.15$$
> $$f(3) = F(3) - F(3^-) = 0.55 - 0.15 = 0.40$$
> $$f(5) = F(5) - F(5^-) = 0.85 - 0.55 = 0.30$$
> $$f(7) = F(7) - F(7^-) = 1.00 - 0.85 = 0.15$$
>
> **Bước 2:** PMF hoàn chỉnh:
> | $x$ | 1 | 3 | 5 | 7 |
> |---|---|---|---|---|
> | $f(x)$ | 0.15 | 0.40 | 0.30 | 0.15 |
>
> **Bước 3:** Tính $P(3 \leq X < 7)$:
> $$P(3 \leq X < 7) = f(3) + f(5) = 0.40 + 0.30 = 0.70$$
>
> Hoặc dùng CDF: $P(3 \leq X < 7) = F(7^-) - F(3^-) = 0.85 - 0.15 = 0.70$ ✅
